# Bathroom Reset Checklist Cards

## Product type

Owned digital product. Can later become print-on-demand cards.

## Product promise

Simple checklist cards that help a bathroom, shower shelf, or family self-care space feel cleaner, calmer, and easier to use.

These cards are for organization and routine support only. They do not make health, skin, hair, or child-development claims.

## How to use

Print or save each card. Place the card where it supports the routine: bathroom shelf, towel area, planner, or family command center.

## Card 1: The daily bathroom reset

- [ ] Put products back in place
- [ ] Hang or place towel properly
- [ ] Clear sink area
- [ ] Wipe visible water or product mess
- [ ] Return tools to their spot
- [ ] Remove empty packaging
- [ ] Leave the space ready for next use

## Card 2: Shower shelf reset

- [ ] Keep only current ritual products
- [ ] Remove duplicates
- [ ] Remove empty bottles
- [ ] Check tool condition
- [ ] Keep cleanse, polish, moisturize, scent, and reset items separate
- [ ] Make the first step easy to reach

## Card 3: Towel and robe reset

- [ ] Fresh towel ready
- [ ] Used towel handled
- [ ] Robe or comfort item available
- [ ] Laundry basket clear
- [ ] Towel area dry

## Card 4: Family bath-time setup

For parents and family households.

- [ ] Towel ready
- [ ] Bath tools ready
- [ ] Products selected before starting
- [ ] Extra products out of reach
- [ ] Cleanup plan ready
- [ ] Bathroom reset after use

## Card 5: Hair-care tool reset

- [ ] Brush or comb stored clean
- [ ] Scalp tool stored dry
- [ ] Hair accessories placed together
- [ ] Towel ready
- [ ] Products returned to storage

## Card 6: Product clutter check

- [ ] I used this product this week
- [ ] I know its ritual role
- [ ] It is not expired or empty
- [ ] It does not duplicate another item
- [ ] I would buy it again

If three or more answers are no, remove it from the main shelf.

## Card 7: Guest-ready bathroom reset

- [ ] Clean towel visible
- [ ] Sink area clear
- [ ] Soap available
- [ ] Trash handled
- [ ] Strong clutter removed
- [ ] Simple scent or fresh-air cue

## Card 8: Sunday reset

- [ ] Review products used this week
- [ ] Remove what did not get used
- [ ] Restock only essentials
- [ ] Clean tools
- [ ] Plan next week’s ritual
- [ ] Write one product to stop buying

## Card 9: Buy or skip card

Before buying, ask:

- [ ] What role does this product fill?
- [ ] Will I use it this week?
- [ ] Do I already own something similar?
- [ ] Is the seller making exaggerated claims?
- [ ] Does this make my routine easier?

Buy only when the product has a clear role.

Repeat this before adding more products.
